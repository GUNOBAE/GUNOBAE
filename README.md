# Hi, I'm Geonho Bae 👋

I'm a Mechanical and System Design Engineering student at **Hongik University**, also pursuing a multidisciplinary major in **Intelligent Robotics**.

I enjoy building robots from the ground up — mechanical design, 3D printing, electronics, embedded systems, and control.  
Most of my projects are hands-on builds where I learn by designing, fabricating, testing, breaking things, and improving them.

## 🤖 Projects

### [WALL·E Robot](https://github.com/GUNOBAE/WALL-E)
A university team project based on an open-source WALL·E platform, with additional work on electronics integration, charging, cooling, and battery monitoring.

### [InMoov Robot Hand](https://github.com/GUNOBAE/BGH_ROBOT-HAND_inmoov)
A servo-driven robotic hand using tendon-like strings and springs to reproduce finger motion.

### [Quadruped Robot](https://github.com/GUNOBAE/quadruped_robot_bgh)
An ongoing 17-DOF quadruped robot project using Raspberry Pi 5 and ROS 2.

### [BMO](https://github.com/GUNOBAE/BGH_BMO)
A custom BMO-inspired robot project involving PCB design, embedded electronics, mechanical design, and software integration.

### [AmazingHand Enhanced Build](https://github.com/GUNOBAE/BGH_AmazingHand-Enhanced-Build)
An ongoing build based on the open-source AmazingHand project, focused on fabrication, control, and future robot-arm integration.

## 🛠️ How I work

I use GitHub as the technical archive for my projects — including build notes, BOMs, CAD/PCB resources, code, references, and troubleshooting.
